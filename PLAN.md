## 0. Цель

Лёгкий и быстрый сайт инструментов, который работает **полностью в браузере** (без БД, без серверных API, без сторонних API, без валют/курсов) и берёт поисковый трафик так же, как piliapp.com: **отдельная индексируемая страница у каждого инструмента и у каждого варианта** (каждый эмодзи, символ, город, часовой пояс, таймер на N минут, пара единиц «км в мили», стиль шрифта, HTTP-код, MIME-тип, число римскими цифрами и т. д.). Дизайн — свой. Название — одна константа в конфиге.

Целевой объём: **~9 200 страниц на язык, ~18 400 всего** (сейчас 1 526 на язык, из них 1 349 страниц `/catalog/*` — мусорные дубли).

## 3. ОТЧЁТ — ОШИБКИ

### 3.1 Архитектура, SEO, инфраструктура
1. JS 1,6 МБ на каждой странице; иконки Phosphor целиком (~564 КБ) и весь `tools.ts` (~202 КБ) в общем бандле.
2. Header — клиентский компонент, импортирует всю базу инструментов и иконки; Radix-меню с хаками `pointer-events` (`releaseStalePointerLock`) — признак багов модальных слоёв.
3. 1 349 страниц `/catalog/*` дублируют `/symbols`, `/emojis`, `/actual-size`, `/time-now` → дублированный контент, числовые URL без смысла.
4. Две параллельные системы sitemap: `/sitemap/*` и `/sitemaps/*`.
5. Серверные API противоречат концепции: `/api/fetch-url` (прокси — риск SSRF/злоупотреблений), `/api/diagnostics/ip`, `/api/indexnow/submit`, `/api/sitemap/crawl`, `/api/og`.
6. `/what-is-my/ip`, `ipv4`, `ipv6` требуют сервер — несовместимо с «только браузер».
7. `x-default` hreflang указывает на `ru` вместо нейтральной версии.
8. Ложные обещания в текстах: «Более 3 000 утилит», «65 тестов железа», пункты меню «Блог», «Войти/Выйти» (нет ни блога, ни авторизации).
9. Бренд захардкожен в разных местах: `messages/*.json` («Ultimate Tools», «RC Web App»), Footer/searchIndex («PilliApp»), тест `global-search.test.ts`, коды верификации Google/Yandex прямо в `app/[locale]/layout.tsx`.
10. `.gitignore` игнорирует favicon, manifest, sw.js, шрифты, vendor, `BingSiteAuth.xml` → при коммите сайт теряет ассеты.
11. `package.json`: `engines` требует Node 24, локально Node 26; override `undici` ломает `npm outdated`.
12. Две системы дизайн-токенов одновременно (`tokens.css` `--rc-*` HSL и `@theme` в `globals.css`).
13. SEO-тексты генерируются «спиннингом» (`uniqueMetaEngine.ts`, 41 КБ: выбор шаблонной фразы по хэшу FNV-1a) — низкокачественный шаблонный текст, одинаковые FAQ-вопросы на всех страницах.
14. OG-изображение рендерится динамически для каждого инструмента, маршрут принимает **любой** слаг (200 на мусор), без кэша, без кириллического шрифта; `/api/og` рисует любой `?title=` на нашем домене с кэшем на год (злоупотребление).
15. **Корень сайта `/` отдаёт 404** — нет `app/page.tsx` и редиректа; ссылки «на главную» из страницы ошибки ведут на 404.
16. **Все программные страницы отрисовываются без стилей**: классы `bg-card`, `text-muted-foreground`, `bg-secondary`, `bg-muted`, `text-foreground`, `bg-background` используются в 26+ файлах, но не определены (в собранном CSS их нет); скелетоны невидимы.
17. **Бесконечные дубли URL**: `/ru/emojis/smileys/x/y/…` отдаёт 200 с каноникалом на себя (`emojis/[...slug]/page.tsx:31,37`).

20. Страница ошибки только на русском, 404 только на английском со ссылками на `/ru`, глобальная 404 всегда `lang="ru"`.

### 3.3 Конвертеры единиц (17 файлов)
1. **Точность 0 знаков обрезает нули целых чисел**: регэксп `/\.?0+$/` → 100 → «1», 240 → «24» (ColorConverter:517, Length:135, Weight:137, Temperature:92; тот же баг в Loan:58, Mortgage:56, Percentage:82, TaxCalc:29).
2. Energy: пресеты ссылаются на несуществующие единицы `megajoule` (:119) и `british-thermal-unit` (:121) → «100 BTU → кДж» показывает «100 кВт·ч = 360 000 кДж».
3. Кнопка «поменять местами» записывает в поле `9.4607e+15`, а парсер экспоненту не принимает (Length:203/:124).
4. Ввод: заменяется только первая запятая; «1 000» не принимается нигде; вывод всегда с точкой даже в русском; при обмене теряется точность; «точность» в одних файлах — знаки после запятой, в других — значащие цифры; три разных реализации копирования; отрицательные числа запрещены в 7 файлах.
5. Area: `Number()` принимает «0x1F» как 31; пресет «10 соток» при единице «Ары»; у select нет label.
6. ColorConverter: LAB/OKLCH только на вывод; `lab-d65()` — невалидный CSS; проценты в `rgb()` читаются как 0–255; у серых шумный оттенок OKLCH; HSV/CMYK теряют альфу; две кнопки копирования.
7. Coordinate: только DD → DMS/DDM, обратного нет; при неверном вводе остаётся старый результат и копируется (:183-198); «UTM» — только номер зоны без easting/northing; кнопка геолокации дважды.
8. Нет единиц: ПБ/ПиБ, кгс/см² (атмосфера техническая), мм вод. ст., пуд, центнер, короткая/длинная тонна, имперские пинта/кварта/унция, фут³, дюйм³; Mach зафиксирован 343 м/с.
9. Cooking: «стакан» = американская чашка 236,6 мл (русский гранёный — 200/250 мл).
10. NumberSystem: префикс `0x` убирается только в режиме hex; нет дробей и дополнительного кода; `inputMode="decimal"` прячет минус на iOS.
11. FileConverter: `pdf-lib` статически импортирован в базовый чанк (pdf-engine.ts:1).

### 3.4 Для разработчиков (22 файла)
1. **Cron**: не принимает `1-10/2`, списки с диапазонами, `JAN`/`MON`, день недели 7, `@daily`, Quartz `? L W #`; `*/2` трактуется неверно; поиск следующих запусков перебором до 525 тыс. итераций (5,18 млн с секундами) — **зависание страницы**; 29 февраля «нет запуска»; включение секунд даёт «каждую секунду»; в списке пресетов видно 5 из 10; падежи «с январе по марте».
2. **CssMinifier ломает CSS**: `content:"/*x*/"`; схлопывает пробелы в строках и `url()`; `calc(1px + 2px)` → невалидный `calc(1px+2px)`; `.a :is(.b)` → `.a:is(.b)` (меняет смысл); `0px` → `0` ломает `flex`, переменные и имена классов; понижает регистр `#ID`-селекторов; инлайнинг переменных игнорирует `.dark`/`@media`; добавляет фейковые `-ms-box-shadow`; удаляет `-webkit-line-clamp`; «gzip ≈» — выдуманная формула; «сравнение» не является diff.
3. **RegexTester: подсветка совпадений не работает** — санитайзер вырезает `<mark>`; регэксп выполняется на каждый символ в main thread, паттерн берётся из URL → ссылкой можно подвесить вкладку; нет флагов u/y/d/v; группы не показываются; экспорт кода в Python/Java/Go неверный.
4. **SqlFormatter портит запросы**: после `--` комментирует следующий код; схлопывает пробелы в строках; разрывает `BETWEEN … AND`; поднимает регистр в кавычках; минификатор режет строку по `--` внутри литерала.
5. **YamlJson — самописный парсер**: `- http://x` → объект, `- 12:30` → `{"12":30}`; нет блочных скаляров, якорей, нескольких документов, табов; большие числа и «007» портятся; при выводе «Norway problem» (`no`, `yes`, даты без кавычек).
6. JsonFormatter: ввод сохраняется в URL-хэше (секреты попадают в историю браузера); 60 строк мёртвого скрытого тулбара; JSON парсится 3 раза; по div на строку в нумерации (100k строк = 100k узлов); «Python dict» заменяет true/false/null внутри строк.
7. JsonCsv: защита от CSV-инъекции добавляет `'` к отрицательным числам (`'-5`); `Math.max(...rows)` переполняет стек на ~100k строк; вложенные объекты не разворачиваются.
8. ColorPicker: оттенок теряется при s=0/v=0 (:243) — тянешь в серый, палитра прыгает в красный; только 6-значный HEX; холсты недоступны с клавиатуры.
9. DiffChecker / myersDiff: копия массива V на каждом шаге → ~800 МБ на двух разных текстах по 5k строк («100 000 строк» в комментарии — неправда); без обрезки общих префиксов; `\w` ASCII — кириллические слова сливаются с пунктуацией; split-вид рассинхронизируется; задачи воркера копятся без отмены.
10. HtmlFormatter: Prettier (≈260 КБ gz) в main thread. JsBeautifier: на деле Prettier, TS-парсер 209 КБ gz, воркер не завершается.
11. JWT: бейдж «Действителен» проверяет только `exp` по замороженному времени, игнорирует `nbf`, не срезает «Bearer », не предупреждает об `alg:none`.
12. HttpStatus: 53 кода, нет 203, 205, 208, 226, 300, 305, 417, 421, 510, 419, 444, 499, 520–527. MimeTypes: 50 записей; зависимость `file-type` не используется вообще.
13. RegexLibrary: TLD не принимает `xn--p1ai` (.рф); IPv4 принимает «01»; IPv6 только полная форма; Base64 совпадает с пустой строкой; тестер без флага `m`.
14. XmlFormatter: отклоняет любой DOCTYPE; падает на BOM.
15. BoxShadow: парсер понимает только px; `rgb()`/`hsl()` ломают прозрачность; превью всегда фирменным цветом.
16. Chmod: нет ввода `rwxr-xr-x`/`u+x`/umask; предупреждение на законный `1777`.
17. CssAnimation: превью игнорирует reduced-motion; принудительный префикс `ulti-`.
18. Flex/Grid Playground: настройки удалённых элементов остаются в CSS.
19. GithubReadme: любой ввод стирает результат; URL скачивания отзывается сразу после клика.
20. Логика Prettier-плагинов продублирована в `formatCode.ts` и воркере.

### 3.5 Цвета и развлечения
1. ContrastChecker: показывает «4.50:1» и «Не проходит AA» одновременно (#6363F8) — округление при показе и неокруглённая проверка; альфа отбрасывается; `transparent` = чёрный.
2. ColorWheel: «Базовый» цвет не совпадает с введённым в 89 % случаев; вывод «225°, 100°, 60%»; порог цвета текста 0,35 даёт контраст 3:1; колесо не рисуется.
3. ColorBlender: режимов наложения нет (название вводит в заблуждение); серые в HSL идут через пурпурный.
4. ImageColors: AVIF гоняется через 15-МБ ImageMagick без нужды; гонка при быстрых загрузках; полная декодировка в main thread.
5. Countdown: формат только ММ:СС («1440:00»); `aria-live` обновляется 10 раз/с (глушит скринридеры); дубль таймера.
6. TeamGenerator: первая команда всегда получает лишнего; «2 участников», «3 команд».
7. RandomPicker: `autoFocus` крадёт фокус; режимы спрятаны.
8. **Обратные отсчёты до событий считаются на сервере при сборке (UTC)**: Новый год наступает в полночь UTC, после события страница показывает 0 до следующего деплоя.
9. `cryptoRandom.ts` существует, но используют его 3 файла; ещё 6+ копий генераторов случайных чисел; выше 2³² — смещённое распределение; тихий откат на `Math.random`.

### 3.6 Калькуляторы и финансы
1. **Все 15 показывают результат только после кнопки и стирают его при каждом вводе** — плохо для UX и для SEO (ответ не виден в HTML).
2. **Зарплата КЗ**: СО 3,5 % (с 2025 — 5 %), потолок 50 МЗП вместо 7 МЗП; ОПВР 1,5 % (в 2026 — 2,5 %) без потолка; нет социального налога (СН) → стоимость для работодателя занижена; текст противоречит коду (про 15 % ИПН); нет режима «на руки → gross».
3. Пенсионный: доходность по умолчанию 0 % и спрятана → прогноз без роста; нет тенге; взносы копятся годовыми порциями.
4. Ипотека: копия кредитного (~280 строк), без дифференцированных платежей, без URL-состояния.
5. Кредит: нет округления до тиынов (не сходится с банком); в дифф. режиме скрыта «Итого».
6. Проценты: режимы спрятаны; нет «X — это Y% от какого числа», разницы, п.п.
7. SalaryCalc — одна ставка и валюта «CUR»; TaxCalc — `(доход−вычеты)×ставка`, период меняет только подписи.
8. Чаевые: доля на человека не округляется (3 × 33,33 = 99,99).
9. Бюджет: нет обещанного 50/30/20. Инфляция: нет данных ИПЦ. Депозит: дробные периоды, нет пополнений. Инвестиции: запрещают отрицательную доходность.
10. Научный калькулятор: глобальный перехват клавиш на всей странице; функции спрятаны.
11. 6 разных парсеров чисел, 4 способа работы с валютой, 0 тестов.
12. НДС Казахстана: с 2026 года 16 % (проверить) — текущие тексты используют 12 %.

### 3.7 Генераторы
1. Хэши: SHA через `crypto.subtle` — не работает по http; SHA-1/384/512 читают файл целиком (обещано до 4 ГБ → падение по памяти); «параллельная» пакетная обработка на деле последовательная; ошибки глотаются; английский текст в русском UI; 2 реализации MD5 и 3 — CRC32.
2. UUID только v4; переключатели прячут результат.
3. Slug: казахские/украинские буквы превращаются в разделители: «Қазақстан» → «aza-stan».
4. Mockdata: «user001@demo.invalid» — не реалистично; JsonDataGen — полный дубль.
5. Случайные имена: 20 имён на язык, нет казахских.
6. ColorPalette: порог 0,42 даёт нечитаемые подписи; HSL неперцептивен. Gradient: максимум 3 цвета, нет живого превью.
7. PasswordStrength: словарь из 12 паролей; «типа символов».
8. Avatar: `next/image` поверх blob (бессмысленно); Arial в SVG.

### 3.8 Дата, время, здоровье, кодирование
1. Calendar: «сегодня» в `useState` (расхождение сервер/клиент); ячейки не кликаются; `aria-live` на всю сетку.
2. DateDifference: рабочие дни без праздников КЗ; «сегодня» заморожено при загрузке модуля.
3. Timer: круги хранят общее время, а не отрезки; включение звука во время работы не работает; фоновая вкладка задерживает сигнал; нет часов; заголовок вкладки не обновляется.
4. TimezoneConverter: поиск только по IANA («Алматы» не находится); кнопка «Конвертировать» на деле копирует; английский плейсхолдер; комбобокс без стрелок.
5. UnixTimestamp: 13 цифр в режиме секунд → год ~55 000 без предупреждения.
6. WorldClock: `aria-live` на секцию, перерисовываемую каждую секунду; день/ночь фиксировано 6–20.
7. WeekNumber: текущая неделя не показывается до нажатия; английский текст в RU.
8. BodyMetrics = только ИМТ; нет классов ожирения I–III, азиатских порогов; дюймы без футов; смена единиц стирает ввод.
9. Беременность: срок не сдвигается на длину цикла, а дата родов сдвигается → при цикле 35 дней в ПДР «41 нед. 0 д.».
10. Пульс: только 220−возраст и 2 зоны.
11. Base64: отвергает base64url, без паддинга и `data:`-префикс; «большие файлы» всё равно читаются целиком.
12. HtmlEncoder декодирует только 6 именованных сущностей (`&laquo; &mdash; &copy;` остаются).
13. **Морзе: в русском интерфейсе «SOS» кодируется как «[?] [?] [?]»**; нет казахских букв; звук на `setTimeout` дрожит.

### 3.9 Фейковые функции и нарушения концепции
1. **«Защита PDF паролем» не шифрует**: `pdfEncryptor.ts` только дописывает запись `/Encrypt`, содержимое остаётся читаемым; при этом портит все байты ≥ 0x80 (декодирует файл как latin1 и кодирует в UTF-8, :4, :44); для PDF с xref-потоками возвращает исходник, а интерфейс сообщает «успешно»; заявлен AES, которого нет.
2. **Кнопка «Построить» в графиках ничего не делает**: `onClick={() => {}}` (GraphPlotter:477).
3. **Статистика ломает русский ввод**: «1,5» разбивается на числа 1 и 5 (StatisticsCalc:47).
4. `esign-pdf` перенаправляется на PdfStudio, где подписи нет; `protect-pdf` в `tools.ts` описан как «сравнение SHA-256».
5. **Сетевые вызовы вопреки концепции**: YouTube-превью → `noembed.com` и `img.youtube.com`; генератор sitemap → `/api/sitemap/crawl`; плотность ключевых слов и извлечение текста → `/api/fetch-url`; «Что у меня» → ipify, Google STUN, `/api/diagnostics/ip`; Text-to-Speech с «Google»-голосами Chrome отправляет текст в облако Google без предупреждения.
6. **Ложные SEO-тексты и FAQ в структурированных данных** (риск санкций за спам разметкой): колесо фортуны (обещает crypto-случайность, веса, сохранение списков — ничего нет), кана (обещает 46 знаков, дакутэн, интервальное повторение — есть 15 знаков), фото на документы («биометрические направляющие», «гарантированно пройдёт проверку»), QR (Wi-Fi/vCard — нет), штрихкод (Code128 — нет), матрицы (собственные значения — нет), римские числа (до 3 999 999 — нет).
7. «BIN-валидатор» зелёный для любых 6–8 цифр и обещает определить банк и страну (базы нет); путается с казахстанским БИН.
8. MAC Lookup — 23 префикса вместо базы IEEE; список портов — 31 порт; KzPostalCode — пропускает любые 6 цифр; KzAddressFormat — склейка строк без данных.

### 3.10 Изображения
1. **Safari сохраняет PNG под именем `.webp`** (canvas молча отдаёт PNG): Converter:316, Crop:909, Rotate:223, `downloadCanvas`, `image-engine.canvasConvert`; тип блоба проверяет только Compressor:458.
2. ImageCompressor: PNG-«сжатие» игнорирует качество (:316) и часто увеличивает файл; нет «оставить оригинал, если меньше» (экономия уходит в минус, :577); JPEG заливает прозрачность; оценка размера перекодирует до 3 полноразмерных изображений на каждое изменение настроек (:340-372).
3. ImageConverter: на выход только JPG/PNG/WebP; «макс. ширина» увеличивает маленькие картинки (:195-200); HEIC/TIFF подписаны как «PNG»; анимированный GIF молча становится первым кадром.
4. ImageCrop (67 КБ): ~330 строк недостижимого UI, включая фейковый переключатель «Сохранить EXIF» (:1654-1676); ручки только мышью; дрейф пропорций у краёв (:611, :697); свободный поворот пересобирает полноразмерный canvas на каждый шаг ползунка.
5. ImageFilters: полный перерендер на каждое движение ползунка; `ctx.filter` может отсутствовать в Safari.
6. ImageRotate: отклоняет GIF/BMP/SVG, которые сам же предлагает выбрать; поворот JPEG на 90° с потерей качества (можно без потерь через EXIF-ориентацию).
7. ImageToBase64: расширение берётся из заявленного MIME, а не из байтов; многомегабайтный вывод в textarea вешает страницу.
8. MemeGenerator: один текстовый блок, нет верх/низ, нет шаблонов; шрифта Impact нет на Android/Linux.
9. PixelArt: >256 цветов молча превращаются в фон (:181).
10. SvgEditor: скачивание/копирование/PNG берут **очищенный** SVG (вырезаны `<use>`, `<animate>`, `<foreignObject>`); «оптимизация» портит файлы с XML-декларацией (:86); `<style>` пользователя протекает в стили страницы.
11. WatermarkImage: дублирующиеся контролы; 9 кнопок позиции без подписей; абсолютные пиксели → разный результат на разных размерах.
12. HtmlToImage: «авто-высота» фейковая (:376); вкладка JS работает в превью, но не в экспорте; веб-шрифты теряются; фейковые шаблоны «Твит», «Платёж».
13. Favicon: цвет темы не валидируется перед вставкой в HTML/manifest (:276); всегда заливает фон; `maxLength=4` режет составные эмодзи.
14. `image-engine.ts`: ImageMagick (15 МБ) работает в main thread; `strip()` удаляет ICC-профили → сдвиг цветов у фото iPhone (P3).
15. Мёртвый код: `image-magick.worker.ts`, `image-transform.worker.ts`, `workerPool.ts` (к тому же никогда не отклоняет задачу при ошибке — зависание), `utils/heic.ts`; из-за этого `heic-to` и `file-type` не используются.

### 3.11 PDF
1. CompressPdf: режим по умолчанию «Сбалансированный» **превращает каждую страницу в картинку** — теряются текст, ссылки, формы (:226-292); режим «сохранить текст» уменьшает JPEG без обновления `/Width`/`/Height` → битые изображения (:174-199); предлагает результат, даже если он больше; кнопка повтора со старым замыканием (:820).
2. MergePdf: зашифрованные файлы молча дают пустые страницы; опция PDF-1.4 + object streams даёт невалидный файл (:331-353); парсер диапазонов сортирует и удаляет повторы → страницы нельзя переупорядочить; оценка размера выдумана.
3. PdfStudio: текст рисуется дважды (:331, :422); смена масштаба стирает рисунки (:151); игнорирует `/Rotate` и CropBox; pdf.js-документ не уничтожается.
4. ProtectPdf: ложное «успешно» (см. 3.9.1); пароль владельца = паролю пользователя; проверка подтверждения пропускается, если поле пустое (:179); посторонняя панель SHA-256 и водяной знак внутри.
5. JpgToPdf: перекодирует JPEG, PNG превращает в JPEG с потерями (:338-364); пиксели = пункты (фото 4000 px → страница 55 дюймов); режим «cover» рисует за полями; два select размера страницы.
6. WordToPdf: самописный парсер DOCX — без таблиц, картинок, стилей; дублирует текст надписей; шрифт без CJK/арабского; прогресс-бар фейковый.
7. PdfToWord / PdfToText: не вырезаются управляющие символы (:36) — Word может отказаться открыть файл; фрагменты склеиваются пробелами → слова разрываются.
8. WatermarkPdf: текст ставится PNG-картинкой (не вектор); игнорирует `/Rotate`; гонка превью при новой загрузке (:160).
9. RotatePdf / SplitPdf: миниатюры старого файла попадают на новый (гонка :98, :124; :293-309); в SplitPdf три разных парсера диапазонов.
10. PdfMetadata: загрузка без `updateMetadata:false` → показывает Producer «pdf-lib» и дату изменения «сейчас».
11. `pdf-engine.ts`: PDF → картинка фиксированно 1,75× (~126 DPI), без очистки и без паролей; `renderPageToCanvas` не вызывает `page.cleanup()`.
12. 9 разных парсеров диапазонов страниц с разной семантикой, 6 рендереров миниатюр.
13. `pdfjs-dist`: в `node_modules` 5.7.284, а в `package.json` ^6.2.108 — lock-файл рассинхронизирован; `pdf-lib` не обновлялся с 2021 года.

### 3.12 Текст и символы
1. **Страницы `/symbols/arrows` и `/symbols/stars` пустые, но индексируются**: фильтр сравнивает `'arrow'.includes('arrows')` (`symbols/[slug]/page.tsx:64`).
2. `/emojis`: 904 эмодзи свалены в «objects/tool»; весь JSON 570 КБ уходит на клиент.
3. TextFormatter (90 КБ): «удалить спецсимволы» удаляет все буквы кроме английских и русских (:179); табуляция жёстко 2; блок «умные кавычки» показывает вывод CSV (:969); ~15 полей без подписей.
4. CaseConverter: `XMLHttpRequest` и `hello,_world` делятся неверно; Title Case превращает NASA в Nasa.
5. Lorem: пусто до нажатия (SEO-страница без контента); русский словарь — 48 выдуманных слов.
6. MarkdownPreview: курсив применяется внутри `href` ссылок (:73-85); санитайзер вырезает `del`, `hr`, `input`, `class` → зачёркивание, линии, чекбоксы и подсветка кода пропадают; `isomorphic-dompurify` тянет jsdom на сервер.
7. RemoveDuplicates: `\r` сохраняется (Windows-строки не считаются дублями), «обрезать» удаляет все пустые строки. TextSort: обратная числовая сортировка даёт NaN для строк без чисел. TextReverse: ломает флаги и эмодзи. TextCleaner: удаление zero-width убирает ZWJ и ломает эмодзи; двойное декодирование сущностей.
8. TextReplace: пресет «удалить пустые строки» без флага `m` не находит ничего (:100); «целое слово» через `\b` не работает с кириллицей (:42); пользовательский регэксп в main thread (ReDoS).
9. StringExtractor: «телефоны» ловят даты и IP (:57); упоминания берутся из email (:89); `1,000,000` разрывается.
10. TextAnalyzer: неверный счёт для CJK/хинди; `aria-live` объявляет каждое нажатие; 5 разных счётчиков слов на сайте дают разные результаты.
11. Транслитерация: ГОСТ-Б ц → `cz` неверно перед i/e/y/j (:55); ЗАГЛАВНЫЙ ввод даёт `ShchUKIN` (важно для паспортов); казахские таблицы без источника; украинский текст определяется как казахский (:106).
12. SymbolCatalog — 59 захардкоженных символов; UnicodeLookup — индекс имён из 38 записей.

### 3.13 Безопасность, сеть, валидаторы
1. Email: `a@1.2.3` признаётся валидным `1.2.0.3` (нормализация через `new URL`, :51).
2. IBAN: 79 из 89 стран, **Россия отсутствует** и отклоняется.
3. ИИН: корректный БИН получает вводящую в заблуждение ошибку «7-я цифра» (:212).

## 8. SEO-АРХИТЕКТУРА (главный приоритет)

### 8.1 Принципы (что делает piliapp и что сделаем лучше)
1. **Одна сущность — один URL.** Каждый инструмент и каждый вариант — отдельная статическая страница с собственным title/H1/описанием.
2. **Точные короткие title** с ключом в начале (и глифом, где он есть): «♥ Символ сердца — скопировать», «Время в Алматы сейчас», «Таймер на 5 минут», «Км в мили — перевод». Бренд — в конце через « — ».
3. **Инструмент над сгибом**, преднастроенный под вариант; ответ отрендерен на сервере.
4. **Плотная перелинковка**: 30–50 ссылок на соседние варианты на каждой вариантной странице (piliapp: эмодзи-страница из 144 слов ранжируется за счёт ~48 ссылок на соседей), хлебные крошки, родительский хаб, связанные инструменты.
5. **Плоские хабы** (`/{раздел}/` со ссылками на все варианты, `/all/` со всеми инструментами) — всё в пределах 3 кликов от главной.
6. Лучше piliapp: meta description на каждой странице (у них нет), hreflang ru/en/x-default в `<head>` и в sitemap (у них нет), BreadcrumbList везде, OG-картинка на семейство, быстрые страницы.
7. **Без «спиннинга»**: уникальность текста — за счёт данных варианта (цифры, факты, таблицы), а не синонимов.
8. **Защита от тонкого контента**: длинные хвосты (числа, пары) — только кураторские наборы с реальным спросом; остальное считается на клиенте без отдельного URL.

### 8.3 Шаблон любой страницы (сверху вниз)
1. Хлебные крошки (видимые + `BreadcrumbList`).
2. **H1** = главный ключ («Время в Алматы сейчас», «Таймер на 5 минут»).
3. Одна строка подзаголовка с ответом/сутью («UTC+5, без перехода на летнее время»).
4. **Инструмент** — сразу, преднастроенный под вариант; первичный результат в HTML.
5. Блок «Варианты» — чипы на 30–50 соседей (другие города этого пояса/страны, другие длительности, соседние символы).
6. Блок фактов/таблица из данных варианта (для города: пояс, смещение, IANA, координаты, восход/закат, разница с Москвой/Астаной/UTC, другие города пояса; для пары единиц: формула + таблица 1–100; для символа: HTML-сущность, U+, Alt-код, ввод на Mac/Windows/Linux, LaTeX, похожие знаки).
7. Короткий статичный текст «Как пользоваться» (2–4 предложения, написан вручную на семейство, подставляются данные).
8. FAQ 3–5 вопросов с ответами из данных (`<details>`; `FAQPage` в JSON-LD только для инструментов, не для тысяч вариантов).
9. Связанные инструменты (6–8 карточек).
10. Подвал со всеми разделами.

### 8.4 Мета и разметка
- `title` ≤ 60 символов, `description` 120–160 символов, оба генерируются из данных варианта, уникальность проверяется тестом на всех страницах.
- `canonical` — на себя; параметры отображения (`?theme=`, состояние инструмента) не индексируются (canonical на базовый URL).
- `hreflang`: `ru`, `en`, `x-default` (→ `en`) в `<head>` и в sitemap.
- JSON-LD: `WebApplication` (инструменты), `BreadcrumbList` (всё), `FAQPage` (инструменты), `WebSite` + `SearchAction` (главная), `DefinedTerm` (символы/эмодзи/HTTP-коды).
- OG-картинки: статичные на семейство (генерируются при сборке), на главную — отдельная.
- `robots.txt`: всё открыто, закрыты параметры; ссылка на sitemap-индекс.
- Sitemap: индекс + отдельный файл на семейство и язык (≤ 50 000 URL), `lastmod` = реальная дата изменения данных (не «сегодня» каждый день), `xhtml:link` альтернативы.
- IndexNow и пинг Яндекса — скриптом после деплоя (не через API сайта).
- Верификация Google/Yandex/Bing — из конфига.

### 8.5 Рендеринг и сборка
- Next.js App Router, **все страницы SSG** (`generateStaticParams`), длинные хвосты (эмодзи, символы, пары) — SSG с ISR «по первому запросу, навсегда» (`dynamicParams: true`, `revalidate: false`), неизвестные слаги → 404.
- Одна модель данных — **реестр страниц** (`src/registry/*`): раздел → инструмент → вариант; из него строятся маршруты, хабы, перелинковка, sitemap, поиск, мета. Тест проверяет: нет битых ссылок, нет дублей title/description/H1, у каждой страницы ≥ N ссылок на соседей.
- Данные вариантов генерируются скриптами из первоисточников (Unicode CLDR, IANA tzdata через `Intl`, mime-db, IANA HTTP/ports) и хранятся как JSON; на клиент не отправляются целиком.

## 9. ДИЗАЙН-СИСТЕМА (новая, своя)

### 9.1 Характер
Чистый «инструментальный» стиль: светлая «бумага», чёткая типографика, один яркий акцент, почти без теней, акцент на результат (крупные цифры, моноширинные значения). Никаких стеклянных эффектов, градиентов и анимаций ради анимаций.

### 9.2 Цвета (токены CSS, светлая / тёмная)
| Токен | Светлая | Тёмная | Где |

### 9.3 Типографика
- Шрифт интерфейса: **Onest** (вариативный, латиница+кириллица, подключается через `next/font`, один файл ~40 КБ). Моноширинный — системный стек (`ui-monospace, SF Mono, Menlo, Consolas`).
- Шкала: 13 / 15 / **16 (текст)** / 18 / 22 / 28 / 36 / 44 (главная). Заголовки 600–700, межстрочный 1,2; текст 400, межстрочный 1,55; длина строки статьи ≤ 72 символа.
- Цифры в результатах — `font-variant-numeric: tabular-nums`, крупный размер 28–44.

### 9.4 Сетка, отступы, радиусы, тени
- Шаг 4 px: 4, 8, 12, 16, 24, 32, 48, 64. Контейнер 1200 px, поля 16 (мобильный) / 24 / 32.
- Радиусы: 8 px — кнопки и поля; 12 px — панели и карточки; 999 px — чипы.
- **Тени: только у всплывающих слоёв** (меню, диалог, поиск, тост): `0 12px 32px -8px rgb(16 17 20 / .18), 0 2px 6px rgb(16 17 20 / .06)`. Карточки, панели, шапка — без теней, рамка 1 px. Hover карточки — рамка `--border-strong` + подъём на 1 px.
- Фокус: кольцо 3 px `--accent` 35 % + смещение 2 px, всегда видимое при клавиатуре.

### 9.5 Компоненты
Кнопка (основная/вторичная/призрачная/опасная; 36 и 44 px), поле ввода (44 px), числовое поле с русским вводом, textarea с счётчиком, нативный select со своим оформлением, сегментный переключатель, ползунок, переключатель, вкладки, диалог (`<dialog>`), тост, кнопка копирования (иконка → «Скопировано»), зона загрузки файлов, панель результата (крупное значение + копировать + подпись), панель кода, таблица данных, чипы вариантов, хлебные крошки, карточка инструмента (иконка раздела + название + одна строка), `<details>`-FAQ, пагинация для больших хабов, `Kbd`.

### 9.6 Раскладки
- **Шапка 56 px** (без тени, нижняя рамка, липкая): логотип (квадрат-монограмма с первой буквой бренда + название из конфига), поле поиска (десктоп) / иконка (мобильный), кнопка «Все инструменты» (полноэкранная панель со всеми разделами), RU/EN (ссылка на ту же страницу на другом языке), тема (система/светлая/тёмная).
- **Главная**: H1 + крупный поиск; «Популярное» (12 карточек); затем все категории, в каждой — хабы и топ-инструменты (всё ссылками, отрендерено на сервере); «Недавние» — клиентский островок.
- **Хаб раздела**: H1, описание, сетка всех инструментов/вариантов (для эмодзи — сетка глифов с группами и пагинацией).
- **Страница инструмента/варианта**: шаблон §8.3; панель инструмента на всю ширину контейнера (формы ограничены 960 px).
- **Подвал**: все разделы, языки, «О сайте», «Конфиденциальность», «Условия», © бренд и год.

### 9.7 Иконки, движение, тёмная тема, доступность
- Иконки `lucide-react`, импорт по одной, 20 px, штрих 1,75; иконки разделов — 24 px на цветной плашке.
- Анимации: только CSS-переходы 150 мс ease-out (hover, нажатие, открытие меню); `prefers-reduced-motion` отключает всё. `framer-motion` удаляется.
- Тёмная тема: класс на `<html>` ставится inline-скриптом до отрисовки (без мигания), выбор хранится в localStorage.
- Доступность: WCAG 2.2 AA, видимый фокус, skip-link, landmarks, подписи у полей, цели нажатия ≥ 44 px, `aria-live` только на итоговых значениях.

### 9.8 Поиск
Ctrl/⌘+K и поле в шапке → палитра поиска; индекс (инструменты + хабы + топ-варианты) — статичный JSON на язык, загружается при первом открытии; собственный ранжировщик: транслит (ru↔lat), исправление раскладки («ефьук» → «таймер»), синонимы, префиксы.
